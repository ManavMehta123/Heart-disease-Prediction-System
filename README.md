# ❤️ Heart Disease Prediction System

A Machine Learning-based web application that predicts the likelihood of heart disease in a patient based on medical parameters. This system helps in early detection by analyzing health-related attributes and providing prediction results using trained ML models.

---

## 📌 Features

- Predicts heart disease risk using Machine Learning
- User-friendly interface for inputting patient details
- Real-time prediction results
- Data preprocessing and model training
- Accuracy evaluation of ML model
- Clean and responsive UI

---

## 📊 Machine Learning Algorithm Used

The following Machine Learning algorithms were tested:

- Logistic Regression
- Random Forest Classifier
- Decision Tree Classifier
- Support Vector Machine (SVM)

Among these, the best-performing model was selected based on accuracy.
